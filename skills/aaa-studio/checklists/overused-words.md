# Overused AI words (house rule)

**Rule:**
- Names, titles and on-screen text never use these words unless no better word exists.
- **Exception:** the user's own prompt uses the word (if they ask for "neon", they get neon).
- **Worker:** picks a plainer, more specific word.
- **Judge:** each one it finds is a J fix (an AI tell).
